# CypherCart Frontend

Frontend UI for **CypherCart**, built with **React**, **Vite**, and **TypeScript**, connected to the Spring Boot and CognoDB graph-powered backend.

---

## 🌟 Features

* **Storefront Catalog:** Displays gadgets, categories, prices in INR, and stock status.
* **Graph-Powered Recommendations:** Shows product recommendations generated through CognoDB graph traversals.
* **Admin Dashboard:** Add products, manage stock, and remove products.

---

## 🛠️ Technology Stack

* **React** with **TypeScript** & **Vite**
* **Axios** for API communication
* **React Router** for navigation
* **Vercel** for deployment

---

## ⚙️ Setup and Run Locally

1. **Clone the repository:**

```bash
git clone https://github.com/AdityaTalwatkar/cyphercart-frontend.git
cd cyphercart-frontend
```

2. **Install dependencies:**

```bash
npm install
```

3. **Run the development server:**

```bash
npm run dev
```
